# Strings&Harmony

A MERN website for buying and selling guitars.

- `Express/`  the backend (Node, Express, MongoDB with Mongoose)
- `Frontend/` the website (React with Vite)

Setup steps are in `SETUP.md`.

## What the site does
- Anyone can browse and search guitars (by brand/model, type, condition, price)
- Register and log in, add guitars to a cart, check out (cash on delivery)
- Any logged in user can **sell** a guitar, edit or remove their own listings, and see their sales
- The admin can see all guitars, all orders (and change their status) and all users
